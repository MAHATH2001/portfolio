Projects / 01 — Security

Web Phishing Detection using Machine Learning

A growing number of people shop and bank online, and fake e-banking pages that mimic real ones try to harvest usernames, passwords and card details. This project trains machine learning models to tell phishing pages apart from legitimate ones before the user ever enters their data.

View Live Site View Code
// OVERVIEW

Phishing websites imitate trusted e-banking and e-commerce services to trick users into handing over sensitive data. Since web services are one of the most exposed surfaces on the internet, this project focuses on catching those fakes automatically rather than relying on the user to spot them.

Phishing and benign URLs were gathered to build a labelled dataset, then both URL-based and content-based features were extracted from each site. Several ML models and deep neural nets were trained on those features, and their performance was measured and compared to pick the strongest approach.
